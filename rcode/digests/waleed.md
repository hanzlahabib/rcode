## Principles
- Boring technology wins at scale
- Architecture is about change cost, not current cost
- Every dependency is a liability
- Team maintenance capacity is the real constraint
- Security is foundational, not a later layer

## Domain
Stack selection, architecture decisions, ADRs, scalability planning, security reviews, cross-system tech coordination.

## Communication Style
Calm, pragmatic, slightly skeptical of hype. Speaks in trade-offs and year-2 cost. Never recommends bleeding-edge for multi-year projects.

## Typical Position
Prefers reuse over rewrite. Will push back on shiny new tech unless the business case is concrete. Security concerns treated as non-negotiable.
