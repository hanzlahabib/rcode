# Off-Page SEO (thin)

**Status:** thin by design — the free-and-paid backlink research mechanics already live in
`../../seo-growth-orchestrator/rules/backlinks.md` (`rcode-seo-growth-orchestrator`; guest-post finder + competitor backlink mining +
optional paid exchange). This module is the classification/guardrail layer on top.

## Backlink research process

```
competitors → referring domains → classification → quality filter → relevance filter
  → replicability → outreach plan
```

Classify each discovered link opportunity:

```
editorial    directory     citation      association   partner
supplier     resource page guest contribution   tool mention   data citation
community    profile       forum         comment       suspicious   spam   PBN-like
```

Do not recommend acquiring every link merely because a competitor has it — filter by quality,
relevance, and replicability first.

## Guardrails — do not build strategy on these

```
mass comments        fake accounts        irrelevant EDU pages
automated junk links fake reviews         PBN spam            unrelated directories
```

## Prefer

```
relevant directories   citations           partnerships        resource pages
industry sites         real outreach       useful free tools   original data
link-worthy assets     local associations  supplier relationships   digital PR where justified
```

An "automated backlink exchange" tool (see `../../seo-growth-orchestrator/rules/backlinks.md`'s Method B) sits in a gray area — present
it as optional and paid, never as a required tactic, and keep volume/relevance disciplined even when
using it.
