## What Was Built

Inserted the following block into the CLAUDE.md template string inside `cmdGenerateClaudeMd` (at ~line 4555, before the final closing line):

- Section header: `## rcode Command Routing`
- One-sentence intent: check before acting ad-hoc
- **How to check** paragraph: references `.rcode/workflows/do.md` as single source of truth with illustrative examples (not an inline table)
- **Why** paragraph: explains state-divergence risk and `/rcode-memory-update` fallback
- Total: 10 lines of Markdown, within the ≤12 line constraint

All backticks in the inserted markdown are escaped as `\`` consistent with the surrounding JS template literal. `node --check rcode/bin/rcode-tools.cjs` passes.

## Patterns Established

The routing block deliberately omits any inline keyword→command table. It references `do.md` as the single source of truth. This pattern avoids drift: when `do.md` changes with a release, the CLAUDE.md block stays accurate by proxy.
